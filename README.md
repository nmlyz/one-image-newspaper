A single-file Python program that draws a newspaper front page summing up the world news of 21 November 2026 — the Iran war running into 2027, Russian missiles landing in Poland, the UK-EU reset deal agreed in Brussels, Myanmar calling the ICJ's Rohingya genocide ruling unfair, and Peru's magnitude 6.8 earthquake — as one 1024x1024 PNG, drawn entirely with code (a hand-made bitmap font, no external assets) using only the Python standard library.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
